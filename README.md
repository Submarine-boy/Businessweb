# Artisan Bakery Website

A professional, responsive website for a local bakery business located in Ellensburg, WA.

## Features

- **Responsive Design** - Works great on desktop, tablet, and mobile devices
- **Navigation Bar** - Easy navigation to all sections
- **Hero Section** - Eye-catching welcome section with call-to-action
- **Products Showcase** - Display of bakery specialties (bread, croissants, cakes, cookies)
- **About Section** - Business information and customer reviews
- **Contact Section** - Location, hours, contact info, and contact form
- **Smooth Animations** - Professional scroll animations and transitions
- **Modern Styling** - Warm, welcoming color scheme perfect for a bakery

## File Structure

```
├── index.html      # Main HTML file
├── style.css       # Styling and layout
├── script.js       # Interactive features
└── README.md       # This file
```

## How to Use

1. Clone or download this repository
2. Open `index.html` in a web browser
3. Customize the content to match your bakery's information:
   - Business name
   - Products/specialties
   - Contact information
   - Hours of operation
   - Email address

## Customization

### Update Business Information

Edit `index.html` to update:
- Business name (change "Artisan Bakery" to your name)
- Address: 2200 Brick Rd, Ellensburg, WA 98926
- Phone number and email
- Operating hours
- Products and descriptions

### Modify Colors

Edit `style.css` to change:
- `#8B4513` - Primary brown color (saddle brown)
- `#A0522D` - Secondary brown color (rosybrown)
- `#D2691E` - Tertiary brown color (chocolate)
- `#FFD700` - Accent color (gold)

### Add Features

Potential enhancements:
